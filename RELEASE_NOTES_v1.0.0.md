# Ski Extension v1.0.0 — Official Release

🚀 **Ski Extension** skips YouTube ads with a single keypress (`Tab`) or completely hands-free with auto-skip mode.

### 🌟 What's New in v1.0.0
- **⚡ Self-Healing 4-Layer Detection Engine:** Uses 8 weighted heuristic signals to discover YouTube's "Skip Ad" button even when classes and internal IDs are obfuscated.
- **⌨️ Default Hotkey `Tab`:** Conflict-free, non-interfering key navigation that never conflicts with YouTube's default shortcuts.
- **⏭️ Consecutive Ad Handling:** Seamlessly skips double ads ("Ad 1 of 2" and "Ad 2 of 2") on a single keypress or automatically.
- **📱 Touch & Mobile Ready:** Full mobile web YouTube support (`m.youtube.com`) on Firefox for Android and Kiwi Browser, defaulting to auto-skip on touch screens.
- **✨ Complete UI/UX Redesign:**
  - Modern options dashboard with light, dark, and system theme auto-switching.
  - 20px rounded quick-access toolbar popup with auto-skip toggle and real-time stats.
  - YouTube theme-aware frosted glassmorphism toast notification.
- **📊 Enhanced Stats & Privacy:**
  - Track skipped ads, time saved (seconds, minutes, hours, and days), today & this week breakdowns.
  - Opt-in local history tracking with video titles (never sent to any server).
  - 100% local, no analytics, no remote servers, no permissions beyond `storage`.

### 📦 Installation
- **Chrome / Brave / Edge:** Download `ski-1.0.0-chrome.zip`, extract, and load unpacked via `chrome://extensions` (Developer Mode).
- **Firefox Desktop & Android:** Download `ski-1.0.0-firefox.zip` or install from Firefox Add-ons.
- **Source Code:** Download `ski-1.0.0-sources.zip` for building from source.
